# AI 产品视觉识别演示网页

作者：王云龙

这是一个仅供本地展示的高完成度交互网页。它使用 5 张珀莱雅产品图片演示包装识别、产品匹配以及技术、成分、功效和适用人群的结构化输出。

## 环境要求

- Windows 10 或 Windows 11
- Node.js 22.13.0 或更高版本
- PowerShell 7（推荐）

## 本地查看

解压 ZIP 后，在解压目录中打开 PowerShell，依次运行：

```powershell
npm ci
npm run dev
```

终端会显示本地地址，通常为：

```text
http://localhost:3000
```

按住 `Ctrl` 并点击地址，或将地址复制到浏览器中打开。如果 3000 端口已被占用，终端会自动显示另一个地址，例如 `http://localhost:3001`。

查看结束后，在 PowerShell 中按 `Ctrl+C` 停止本地服务。

## 生产模式预览

如需检查正式构建效果，可运行：

```powershell
npm run build
npm run start
```

然后打开终端中显示的本地地址。

## 说明

- 图片上传功能只在当前浏览器中进行本地预览，不会上传文件。
- 当前版本不会调用真实 AI 模型或远程识别接口。
- 页面中的产品资料链接指向珀莱雅官方网站，点击这些链接需要网络连接。
- 页面内容用于视觉技术演示，不构成医疗或个体护肤建议。
